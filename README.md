Sistema Bancário em Python

  Projeto desenvolvido em Python com o objetivo de praticar os principais conceitos da linguagem, incluindo programação modular, funções, orientação a objetos,       estruturas de repetição e manipulação de dados.

    Funcionalidades
    Cadastro de clientes
    Validação de CPF e e-mail
    Login com autenticação por CPF e senha
    Limite de tentativas de acesso
    Consulta individual de contas
    Listagem de todas as contas cadastradas
    Depósito em conta
    Transferência entre clientes
    Exclusão de contas
